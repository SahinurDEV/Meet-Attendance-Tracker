Built for teachers, team leads and anyone who needs to know who was really there.

⚡

Automatic & manual save

Attendance is saved automatically while the call runs and when it ends. Prefer control? Turn auto-save off and hit Save now whenever you like.

⏱️

Accurate timing

First seen, last seen and time in call for everyone. Leaves and rejoins become separate sessions, and gaps aren't counted.

🎙️

Speaking time

Uses Meet's own on-screen speaking indicator to estimate how long each person talked. No audio is ever processed.

🪟

Built into Meet

An Attendance button and live panel sit right inside Google Meet, with search, live status and one-click exports.

📊

Dashboard & history

Every meeting in one place. Search by title, code, date or participant, open the details with a presence timeline, or delete.

📁

CSV, Excel & PDF

Clean exports with the meeting date in the file name. The encoders are bundled in the extension; nothing is loaded from a CDN.

🙈

Ignore my own name

Leave yourself out of lists and exports, choose a 12h or 24h clock and tune auto-save, all from Settings.

🛡️

Robust detection

Several detection strategies plus a MutationObserver keep it working as Meet's layout changes, and short UI glitches are smoothed out.

Install (load unpacked)

Works in Chrome, Edge, Brave and other Chromium browsers (v110+).

  1. Download the code: ZIP or git clone https://github.com/SahinurDEV/Meet-Attendance-Tracker, then unzip it.
  2. Open chrome://extensions.
  3. Switch on Developer mode (top-right).
  4. Click Load unpacked and choose the extension/ folder.
  5. Pin Meet Attendance Tracker from the puzzle-piece menu and join a call.
terminal
# build a store-ready zip
git clone https://github.com/SahinurDEV/Meet-Attendance-Tracker
cd Meet-Attendance-Tracker
npm install
npm test          # unit + browser tests
npm run package   # → dist/meet-attendance-tracker-v2.0.0.zip

Private by design

  • Stored locally. Attendance lives in your browser's extension storage and nowhere else.
  • No network requests. No servers, accounts, analytics, ads or third-party scripts.
  • No audio or video. Only names and on-screen indicators that Meet already shows you are read.
  • Minimal permissions. Just storage, plus a content script on meet.google.com.
  • You're in control. Delete one meeting or everything, or back up to a JSON file.

Please follow your organisation's policies and local laws when recording attendance.

FAQ

Do other participants need the extension?

No. Only the person taking attendance installs it.

Is speaking time exact?

It's a close estimate from Meet's on-screen speaking indicator, sampled about once a second. Meet sometimes shows only some tiles, so open the People panel for the most complete list.

What happens if I reload the Meet tab?

The same meeting is resumed, so you won't get a duplicate.

Does it work with Google Workspace accounts?

Yes, it works with any account that can open meet.google.com in a Chromium browser.
